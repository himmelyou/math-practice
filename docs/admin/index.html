最后挑战时间（lastGameTs）

  1. 学员管理列表与 report 挑战记录均以 runs.json 最新入库局的 ts 为准
  2. 生存放弃（comboOnly）不入库，不会刷新该时间
  3. 若历史数据曾受 comboOnly 污染，部署后请备份 → 点击「回填最后挑战时间」写回 users.json

说明：新记局仅在写入 runs 时更新 lastGameTs；列表展示始终按 runs 最大 ts 计算，与 report 第一行一致。

拆括号得分（5 分/题）

  1. 旧版拆括号 runs.score 按「答对 1 题 +1 分」写入；新版与其它模式一致为 5 分/题
  2. 回填会更新 runs.json 中 mode=expandBrackets 的历史局、同步 recentExpandBracketsRuns，并按 runs 重算 totalScore
  3. 已回填过的局带 expandScorePerCorrect: 5 标记，重复点击不会二次乘算

部署新版主站后，请先备份再点击「回填拆括号得分（×5）」。
