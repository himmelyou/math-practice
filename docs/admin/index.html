闯关达人榜（level-ranking.json）

          
    
            
  1. 仅统计 mode=level 且 cleared=true（L1–L16 全通）的局
    2. 
            
  2. 每人保留一条最佳：用时最短 → 错题更少 → 更早通关（ts 更小）
    3. 
            
  3. 从 runs-by-user 扫描全库并写入 level-ranking.json，同步 hasClearedLevel
    4. 
            
  4. 日常新通关会增量更新；榜文件丢失、恢复备份或需全库重算时使用
    5. 
          

          
操作前请先在「系统备份」Tab 下载备份。

        

        

          
质数达人榜（prime-perfect-ranking.json）

          
    
            
  1. 进榜：mode=primeComposite、掌握 50 题且错题 ≤5（新局 mastered，旧局 score÷5）
    2. 
            
  2. 每人保留最短用时；同用时错题更少，再同则更早 ts
    3. 
            
  3. 质数达人成就仍为无错通关（wrongCount=0），与榜分开
    4. 
            
  4. 日常新局会增量更新；榜文件丢失、恢复备份或改榜规则后需全库重算时使用
    5. 
          

          
操作前请先在「系统备份」Tab 下载备份。
